MapTiler API key

The map needs a MapTiler Cloud API key. It is stored only in this browser.

How to get a free API key
  1. Open cloud.maptiler.com/account/keys (https://cloud.maptiler.com/account/keys/)
  2. Sign up for a free MapTiler Cloud account, or log in. No credit card is needed for the free plan.
  3. On the API keys page, copy your default key, or create a new one.
  4. Recommended: in the key's settings, add cxnub.github.io to the allowed HTTP origins so the key only works on this app.
  5. Paste the key below and tap Save & load map.
